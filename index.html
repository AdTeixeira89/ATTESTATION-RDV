Espace admin — utilisateurs
Une fois connecté, chaque utilisateur a accès à toutes les fonctions de l'app, comme toi — seul cet espace admin reste réservé aux comptes marqués « admin ». Le nom de la personne connectée est indiqué sur chaque attestation générée (« Rempli par »).
Après avoir ajouté quelqu'un ici, clique « Exporter » et partage le fichier via Drive : chaque autre appareil doit « Importer » ce fichier une fois pour reconnaître les nouveaux comptes.
